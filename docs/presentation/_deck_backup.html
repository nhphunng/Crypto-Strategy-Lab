01 · Giới thiệu

Bối cảnh bài toán

Thị trường crypto hoạt động 24/7; giá được biểu diễn bằng biểu đồ nến (Candlestick).

Một cây nến 5 phút chứa: Open · High · Low · Close · Volume. Trader kết hợp nhiều phương pháp phân tích kỹ thuật để tìm điểm vào/ra vị thế:

  • Moving Average (MA) — tốt khi có xu hướng, kém khi đi ngang
  • RSI — bắt quá mua/quá bán, dễ tín hiệu sai khi trend mạnh
  • Bollinger Bands · Support/Resistance · SMC · Wyckoff

Vấn đề: một strategy đơn lẻ không hoạt động tốt trong mọi điều kiện thị trường.

02 · Mục tiêu chính

Trọng tâm: so sánh độ hiệu quả

Biến việc "thử một chiến lược" thành quy trình lặp lại có hệ thống:

  • Cho phép bổ sung chiến lược mới mà không sửa toàn hệ thống
  • Kết hợp nhiều strategy thành composite, đánh giá trên dữ liệu lịch sử
  • Xếp hạng, so sánh độ hiệu quả và tự động tìm tổ hợp tốt hơn

Đây không phải là "tìm chiến lược kiếm tiền", mà là một kiến trúc phần mềm thử nghiệm có hệ thống.

03 · Quy tắc phụ thuộc

Dependency rule

Phụ thuộc đi một chiều, từ ngoài vào trong:

  • domain — không import FastAPI / SQLAlchemy / queue / provider SDK
  • application — điều phối use case, chỉ phụ thuộc protocol/interface
  • infrastructure — cài đặt adapter: DB, queue, market/news/LLM provider
  • api / worker — composition root; không chứa indicator, accounting, scoring

Provider DTO, API DTO, domain object là các contract riêng, mapper luôn explicit.

Kỹ thuật · scoring
scoring.py
def score_metrics(metrics, policy):
    score = 0
    for m in policy.metrics:
        v = clamp(metrics[m.metric], m.lower, m.upper)
        norm = (v - m.lower) / (m.upper - m.lower)
        if m.direction == LOWER:
            norm = 1 - norm
        score += norm * m.weight
    return round(score * 100, 2)

06 · Kiến trúc mở

Trả lời các câu hỏi kiến trúc

  • Thêm strategy mới? 1 class implements Strategy + 1 dòng register() — không sửa 6 module
  • Random → Genetic search? Backtester chỉ nhận CandidateStrategy, không đổi
  • Binance → Binance + OKX? Viết adapter mới, frontend không đổi
  • 100 → 100.000 backtest? Queue + nhiều Worker
  • News lỗi? Sentiment model đổi? Chart vẫn chạy, Strategy Engine không bị ảnh hưởng
  • Kết quả leaderboard thuộc version nào? Fingerprint + provenance đảm bảo độ tái lập
