Update the existing **Landing Page only** of the Crypto Strategy Lab prototype.

Do NOT rebuild the whole product.

Preserve:

* the current dark design system;
* brand name `Crypto Strategy Lab`;
* current color palette and tokens;
* the existing 7-screen product architecture;
* the top-level CTA `Open Strategy Lab`;
* the product positioning as a research / analysis / simulation lab, not a real-money trading platform.

The goal is to redesign the landing page so it feels:

* more beginner-friendly;
* more elegant and editorial;
* more visually connected from one section to the next;
* more polished when users scroll;
* less like separate stacked blocks.

The current problem is that sections feel too isolated, too boxed, and too sharply divided.

The new design should create **one continuous scroll story**.

---

# 1. DESIGN GOAL

Redesign the landing page as a **connected narrative experience**.

When users scroll:

* content should feel like one guided journey;
* sections should visually flow into each other;
* transitions should feel soft, intentional, and premium;
* the product preview should help tie the story together;
* the page should gradually teach the product instead of showing disconnected sections.

The page should feel closer to a **well-crafted product story** than a dashboard homepage.

---

# 11. SCROLL ANIMATION SYSTEM

Add tasteful scroll-triggered animation throughout the landing page.

Animations must feel premium and restrained.

Do NOT overdo them.

## General reveal animation

Apply to headings, copy, cards, timelines, glossary rows, and capability modules:

* opacity: 0 → 1
* translateY: 24px → 0
* blur: 6px → 0
* duration: 0.55–0.75s
* easing: smooth, not bouncy

## Stagger

For grouped items:

* stagger each item by 60–100ms

Use on:

* workflow steps;
* capability items;
* glossary items;
* credibility items.

## Sticky preview transitions

When changing preview states in the How to Use section:

* crossfade content;
* add slight horizontal or vertical movement;
* duration 220–320ms;
* avoid hard cuts.

## Connector animations

As the user scrolls:

* step rail fills gradually;
* process lines draw in;
* active node pulses subtly.

## Hover animations

Use subtle hover motion:

* slight lift of 2–4px;
* border emphasis;
* subtle glow increase;
* icon nudge.

No exaggerated hover bounce.

## Respect reduced motion

If the user prefers reduced motion:

* disable transform-heavy animations;
* keep only opacity transitions.
